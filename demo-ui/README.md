This project was developed as part of Hackathon 3.0 by participants of the African Plan Foundation. It is a prototype Election Voting Interface designed to demonstrate how modern web technologies can be used to build secure, scalable, and user-friendly digital voting systems for civic engagement and classroom learning.

Tech Stack
This project leverages modern web technologies:

Next.js – React framework for building fast, scalable web apps

TypeScript – Strongly typed JavaScript for reliability and maintainability

Node.js – Backend runtime for API routes

next/font – Optimized font loading (using Geist)

Vercel – Deployment platform for seamless hosting and CI/CD
